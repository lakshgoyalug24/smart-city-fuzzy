How the models differ

Mamdani clips fuzzy output shapes by rule strength, merges them and takes the centroid. Smooth and easy to explain, but slowest.

Sugeno uses a fixed number per rule and a weighted average. Fastest, good for control.

Tsukamoto inverts a monotonic output curve per rule to get a crisp value, then takes a weighted average.
